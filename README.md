# MagSafe Wallet Pro Landing Page

This is a responsive and modern product landing page for the **MagSafe Wallet Pro with Stand for iPhone**, inspired by Capes India.

## Features
- Hero Section with product title and image
- Product Features, Highlights, Customer Testimonials, and Gallery sections
- Scroll-based animations using AOS library
- Responsive layout using CSS Grid and Flexbox
- Interactive elements like hover effects and sticky navbar

## Tools and Libraries
- **HTML5**: Structure
- **CSS3**: Styling and responsiveness
- **JavaScript**: Interactivity
- **AOS (Animate On Scroll)**: For scroll animations

## Folder Structure
- `index.html`: Main HTML file
- `style.css`: External stylesheet
- `script.js`: JavaScript for animations and interactivity
